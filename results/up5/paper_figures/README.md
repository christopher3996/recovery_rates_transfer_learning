# UP5 manuscript figures

These files are copies of the figures included in the manuscript, taken from its image directory on 4 November 2026. The UP5 notebook displays them in review mode when locally generated distribution and encoding figures are unavailable. They are supplied for inspection, not as evidence of a new model run.

| Paper figure | Files |
|---|---|
| 4, UP5 histogram | `rr_dist_up5.png` |
| 5, UP5 correlations | `correlation_heatmap_up5.png` |
| 6, individual bond densities | `mdn_dist_sample_1.pdf` through `mdn_dist_sample_4.pdf` |
| 7, portfolio densities | `up5_ft_mdn_density_side_by_side.pdf` |
| 8, categorical encoding | `ft_mdn_transformer_cat_vs_dummy.pdf` |

Figure 9 is generated separately from the saved schema-expansion runs. Rebuild mode writes new figures to its run directory.
